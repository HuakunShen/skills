# 报告结构与交付检查

按用户语言写报告；事实连证据，评价连 claim ID。不用超出证据的“撒谎者”等动机/人格标签。

## 结论与范围

对象、发表日期范围、as_of/时区、cutoff_mode、版本；一段有依据的判断。强调样本及不确定性，区分当前可取得语料与完整历史。

## 数据覆盖

表列发现数、范围内数、获取数、缺失/私密/失败、完整提取数、总时长、年份/语言/类型分布。目录总量未知就写未知。说明预定抽样/种子、漏提抽查、转录数字/否定/说话人复核。

## 观点和评分

按 claim_type、quantifiability、verifiability 分布。显示 occurrences、独立 claims、相关 forecast families 的数量。分别显示支持/反驳/部分/无法判定/待定/缺证/争议。

所有率有公式、分子分母和排除项；严格支持率、可检验性、显式概率 Brier、证据质量、到期核验覆盖分开。综合分不达门槛写“不足以计算”，不写 0。按领域、时期、预测周期及成熟 cohort 分层；近期可单列，不暗中时间衰减。小样本、关联和选材差异不能支撑强行排名。

## 可复查案例

若存在，展示代表性正确、错误、部分、模糊及正常价值判断。每条原话、source URL/时间戳或段落、发表日期、归属、冻结判据、截止日、证据 URL/适用日期、结果和置信度。遵守引用长度和用户授权，不自动公开完整原文。

## 言论习惯与更改

可检验性、确定性、条件遗漏、更新/撤回、事后宣称和原话是否一致。区分观察到的模式与推测动机；未找到更正不等于从未更正。

## 跨期观点与表达

对每个主要议题列时期、平台覆盖、立场短述、原话与定位、前后变化、解释及局限。依 longitudinal-analysis.md 区分立场转变、证据更新、对象/条件变化与真正矛盾，不以政治方向本身作为好坏评分。时间缺口可见；词频/主题比例变化不自动代表立场改变。重大变化至少展示前后两端的材料。

## 主观维度评价

按固定 rubric 展示 5–10 个维度（默认八维），每维 0–10 锚点、模型原分、案例、反例、缺项理由与裁判评价。每项只评价公开表达中可观察的行为；没有材料标 N/A。可以画雷达图和模型分歧表，但不得从多边形面积推出人物排名。修改权重或量表需要新版本，不为了图更好看而换轴顺序或补零。

## Pending 与恢复

列 claim_id、目标、条件、deadline、状态/原因和 next_check_at。说明只是保存待办还是用户另行启用了调度。附运行目录、下一 task ID、缺失资料、许可余额和恢复提示。

## 成本与文件

实际账单、usage 推算、未知/潜在重试和剩余估计分开；注明 STT 与模型/搜索的不同阶段。
交付 report.md、metrics.json、claims.jsonl、occurrences.jsonl、evidence.jsonl、tasks.jsonl、progress.md。启用纵向分析时增加观点快照/转变记录，启用主观评价时增加 rubric、各模型报告/分数与理由；用户要可浏览页面时再生成 report.html、report-data.json 和可选 radar.svg。CSV 是派生表，多值字段用 JSON 字符串，防止 =/+/-/@ 等开头的文本被当电子表格公式。

选择 Notion/Sheets/SQL/Obsidian 时交付对应真实页面/数据表/文件位置，保留逻辑 ID 与证据链；报告区分计算完成与远端同步完成。JSONL 可以仅是工作快照，不要求用户最终通过 JSONL 浏览。

## 多模型意见与统计

记录实际选中的模型/版本/角色、首轮是否互相隔离、同一输入/rubric 哈希、成功/缺席/失败/弃权数。保留每个原始报告、分项评分和依据。展示 n、mean、median、sample variance、SD、min/max/range；n=1 方差为 null。按先定量表评价，别将确定性计数误做成主观评分。

裁判结论单列，写采纳/拒绝理由、未解决异议与用户裁定引用；不得用裁判分替换历史分布。图中误差条明确标模型范围或模型间 SD，不能默认叫 95% CI。样本重采样区间如有，要另写抽样单位、家族关联、方法、重复次数、种子与适用假设；区分模型分歧和数据不确定性。

## 最终检查

- 每个判定回溯原话和证据；无法读全文的限制可见。
- guest/quotation 未冒算本人；定位未伪造。
- pending/value/missing evidence/条件未触发未算成错误。
- 冻结规则、修订和反证齐全，未决冲突未伪装确定。
- 报告计数和费用与账本一致，覆盖不足没有被隐去。
